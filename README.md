# researchpapercomparer
A Streamlit app to compare two research papers using OpenAI GPT-3.5.
Uploads two PDF files and extracts key content for analysis.
Generates KPI-based insights: domain similarity, innovation score, and content overlap.
Provides theme summaries, highlights, and gap analysis for both papers.
Creates keyword-based word clouds for visual comparison.
Exports the comparison report as a downloadable DOCX file.
Uses PyPDF2, WordCloud, Matplotlib, and python-docx.
Ideal for researchers and students to quickly compare academic papers.
Requires an OpenAI API key for GPT-powered insights.
Lightweight, intuitive, and ready for academic use.
